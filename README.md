# ZENX Browser Homepage

ZENX is a sleek, customizable browser homepage featuring a search bar with real-time suggestions, a speed dial for favorite sites, and a dynamic particle background. Built with HTML, CSS, and JavaScript, it uses `localStorage` to save user preferences and bookmarks.

## Features
- **Search Bar**: Search with Google, Bing, or DuckDuckGo, with autocomplete suggestions powered by DuckDuckGo's API.
- **Speed Dial**: Add, edit, or remove favorite sites with favicons.
- **Settings**: Choose themes (Default, Dark, Ocean) and search engines.
- **Responsive Design**: Adapts to mobile and desktop screens.
- **Animated Background**: Lightweight particle animation for visual appeal.
